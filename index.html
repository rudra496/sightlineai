SightlineAI

AI-powered environmental guidance for blind and visually impaired users. Works with Qwen AI online and deterministic fallback offline — so guidance never disappears.

💔 The Problem

Over 2.2 billion people live with vision impairment. Most navigation tools need stable internet — when connectivity drops in rural areas, transit, or emergencies, they silently fail. No one should lose access to safety guidance because a cloud endpoint timed out.

✨ Features

🧠 Qwen AI Engine

Structured guidance with action steps, safety notes, and confidence ratings. Circuit breaker with exponential backoff for reliability.

🔍 Vision Analysis

Real image understanding via Qwen multimodal vision API. Upload photos for instant accessibility guidance.

💬 Conversation Mode

Multi-turn dialogue with context memory. Ask follow-up questions and get contextual guidance across messages.

🔌 Offline Fallback

Deterministic guidance engine that works without any network or API key. 20+ hazard keyword categories with Bangla templates.

🌍 Multi-Language

Guidance in English, Bangla (বাংলা), Arabic (العربية), and Spanish (Español). Voice input adapts to selected language.

🎙️ Voice I/O

Speech recognition for hands-free input. Text-to-speech for eyes-free guidance output. Works with screen readers.

📊 Risk Scoring

Geospatial risk assessment (0-100) from location, route, hazards, time of day, weather, and mobility aid context.

♿ Accessibility Score

Scene analysis with obstacle density, path clarity, sensory cue detection, and actionable recommendations.

💾 Smart Memory

Session history with pin, favorite, search, and export (JSON, CSV, Markdown). SQLite persistence for production.

⚡ WebSocket Streaming

Real-time token-by-token response streaming for instant feedback. Automatic fallback on connection issues.

🐳 Docker Ready

One-command deployment with Docker Compose. Health checks, environment configuration, and volume mounting.

🔒 Secure by Default

Rate limiting, CSP headers, input validation, bounded uploads, request tracing, and circuit breaker pattern.

🚀 Quick Start

# Clone & run in 60 seconds
git clone https://github.com/rudra496/sightlineai.git
cd sightlineai
pip install -r requirements.txt
uvicorn app.main:app --reload

# Or with Docker:
docker-compose up -d

Open http://localhost:8000 — works immediately with offline fallback. Add a DashScope API key for live AI responses.
